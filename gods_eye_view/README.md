# God's Eye View

![God's Eye View logo](https://raw.githubusercontent.com/nict41/nict41-s-HA-Apps/main/gods_eye_view/logo.png)

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

A real-time intelligence console for planet Earth: a photorealistic 3D globe with live aircraft, ships, satellites, earthquakes, wildfires, traffic and public cameras, a cockpit view for riding along with anything you track, and optional voice control.

## Features

- Packages [bilawalsidhu/gods-eye-view](https://github.com/bilawalsidhu/gods-eye-view) (MIT) unchanged, with the Home Assistant wiring around it
- Works with no API keys; add keys to unlock more data sources
- Available in the sidebar through ingress, plus an optional direct port with its own login screen

## Documentation

Setup, options and troubleshooting are in the app's **Documentation** tab in Home Assistant, or in [DOCS.md](DOCS.md).
